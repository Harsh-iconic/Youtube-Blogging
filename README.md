

# 📺 YouTube Blogging Website

A full-stack blogging platform built with Node.js, Express.js, MongoDB, EJS, and Multer. Users can create an account, publish blogs with images, explore blogs shared by other users, and engage through comments.

## 🚀 Live Demo

🔗 https://youtube-blogging.onrender.com

---

## ✨ Features

- 🔐 Secure User Signup & Login
- 📝 Create and publish blogs
- 🖼️ Upload images with blogs using Multer
- 👀 Browse blogs shared by other users
- 💬 Comment on blogs
- 📱 Responsive and user-friendly interface

---

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- Multer
